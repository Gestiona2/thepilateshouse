# Aira, The Pilates House: sitio web

Sitio estático (Astro) de Aira. El texto editable vive en `src/datos/`.

```bash
npm install          # una vez
npm run dev          # vista previa en http://localhost:4321
npm run build        # compila a dist/
npm test             # valida datos, activos y páginas
npm run revisar-demo # lista los datos de demostración que quedan
```

**Datos de demostración:** hoy el contacto, las clases, los precios, los horarios y los
testimonios son inventados. Ver `PENDIENTES.md`. Para ayuda con el sitio, abrir el asistente
leyendo `AGENTS.md`, o ver `TUTORIAL.md`.
